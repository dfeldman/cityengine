# Famous buildings we are missing or faking

Owner: *"often these are fine with a reface or a kit. just make sure we're not missing a famous one."*

So the filter is narrow on purpose: **only buildings with a real `wikipedia=` article** in OSM (not merely a
`wikidata` id, which nearly everything has), inside the box, that currently have **no model**, a **`fromRecipe`
one-liner** (a generic box wearing a specific builder name — what the Old Mint was), or **reface only**.

79 of them. The point of this file is not to model all 79; most are fine as kit or reface. The point is that
nothing on this list should be a surprise later.

**Alcatraz** has seven of these with no model — Model Industries, New Industries, the Warden's House, the
Powerhouse, the Morgue, the Dining Hall and the Island Lighthouse. The owner asked for Alcatraz to be visible
from the water even though it is unreachable, so these are silhouette work, not detail work.

**Lighthouses** with no model: Alcatraz Island, Point Bonita, Mile Rocks, Point Blunt.
