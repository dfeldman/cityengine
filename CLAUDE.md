This project is a bicycling game with realistic worlds
representing San Francisco (including some suburbs) 
and Paris (including La Defense, excluding eastern edge). It runs in the browser with BabylonJS.

It includes terrain, roads, NPCs, cars, plants, and 
buildings. You will spend most time writing code to 
render buildings, especially specific unique buildings.

It is imperative to use minimal tokens to get the job
done. Taking photos is expensive since they live in 
context; use tinyres mode to find the right shot, and 
take in lowres mode if possible. When running shell 
commands with long output, use tail. Start subagents 
with Haiku or Sonnet when practical. When context 
increases beyond 150k or so, or the task changes, 
remind the owner to compact. Try to build code with 
tunable constant numbers so you can adjust them 
rather than rewrite code. Don't spend more than 30 
turns without user input unless given permission.
